# FATEH STEEL SERVICES

Official web portal for **FATEH STEEL SERVICES** — Manufacturer, stockist, and supplier of Special Alloy Steel, Carbon Steel, Tool & Die Steel, Bright Drawn Bars, Hexagons, and RCS Billets.

---

## 🌟 Key Features

- **Responsive Architecture**: Built with modern semantic HTML5, CSS3, and Vanilla JavaScript.
- **Dynamic Steel Grades Matrix**: Comprehensive directory of Carbon, Alloy, Tool, Ball Bearing, and Case Hardening steel specifications.
- **Interactive Steel Weight Calculator**: Real-time metric weight estimation for Round Bars, Hexagonal Bars, and RCS.
- **Visuals & Animations**: Interactive product showcase, smooth scrolling, and dynamic user interface.
