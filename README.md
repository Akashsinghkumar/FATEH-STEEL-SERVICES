# FATEH STEEL SERVICES

Official enterprise web portal for **FATEH STEEL SERVICES** — Premier manufacturer, stockist, and supplier of Special Alloy Steel, Carbon Steel, Tool & Die Steel, Bright Drawn Bars, Hexagons, and RCS Billets.

---

## 🌟 Key Features

- **Responsive Architecture**: Built with modern semantic HTML5, CSS3, and Vanilla JavaScript.
- **Dynamic Steel Grades Matrix**: Comprehensive directory of Carbon, Alloy, Tool, Ball Bearing, and Case Hardening steel specifications (`steel-data.js`).
- **Interactive Steel Weight Calculator**: Real-time metric weight estimation for Round Bars, Hexagonal Bars, and RCS.
- **Cinematic Visuals & Animations**: GSAP, ScrollTrigger, SplitText typography, interactive cursor, and Swiper carousel.
- **Production-Ready & Static Deployable**: Can be hosted directly on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or any web server.
